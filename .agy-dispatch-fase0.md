2. Generar migracion SQL

### Link en login
- En app/(auth)/components/login-form.tsx (o la pagina si el form esta inline): agregar debajo del form un link "Olvidaste tu contrasena?" que vaya a /login/recuperar

### Pagina /login/recuperar
- Ruta: app/(auth)/login/recuperar/page.tsx
- Form: campo email + CAPTCHA Turnstile (mismo componente que usan login/registro)
- Server action requestPasswordResetAction(formData):
  1. verifyTurnstileToken
  2. rate limit: checkRateLimit('password_reset_request', 5, 60) por IP
  3. Buscar usuario por email
  4. SIEMPRE mostrar al usuario: "Si el correo existe, te enviamos un link para restablecer tu contrasena." (no revelar existencia)
  5. Si usuario existe: generar token crypto.randomUUID(), insertar en passwordResetTokens con expiresAt = new Date(Date.now() + 60*60*1000) (1 hora), enviar email con link https://volunti.co/login/resetear?token=TOKEN
  6. Si no existe: no hacer nada

### Pagina /login/resetear
- Ruta: app/(auth)/login/resetear/page.tsx con ?token=xxx
- Server action validateResetToken(token) o validacion inline:
  - Buscar token en passwordResetTokens donde expiresAt > now()
  - Si no existe o expiro: mostrar error y link a /login/recuperar
  - Si valido: mostrar form con nueva contrasena + confirmar contrasena
- Validacion: minimo 8 caracteres, deben coincidir
- Server action resetPasswordAction(token, password):
  1. Buscar token valido en passwordResetTokens
  2. Si no: return error
  3. Buscar usuario por email del token
  4. Hashear nueva contrasena: bcrypt.hash(password, 10)
  5. Update users.passwordHash
  6. Delete from passwordResetTokens where token = token
  7. Return success -> UI muestra mensaje "Contrasena actualizada. Inicia sesion." + link a /login
